Diagnosis

Two distinct failure modes. Mode 1 — representation collapse: slot embeddings converge to (near-)identical vectors, so the decoder can't tell slots apart. Mode 2 — assignment collapse: the soft assignment Aik degenerates (few slots absorb all nodes) or goes uniform (no confident regions). Healthy territorial overlap at boundaries is expected — different from collapse.

Mode 1 · Slot-embedding distance

Pairwise distance between the K slot embeddings (torch.cdist(slots, slots)), scaled by the max off-diagonal distance. Near-zero off-diagonal cells (▼ blue) mean two slots have collapsed to the same point. Norm-value ≈ 0 anywhere ⇒ collapse.

Slot × slot distance

Blue = near-identical slots (collapse); red = well-separated. Values are distance ÷ max off-diagonal.

Per-slot usage marginal

A_ik.mean(dim=0) — share of all assignment mass each slot receives. Black dashed line = uniform 1/K. Lopsided ⇒ degenerate collapse; flat ⇒ uniform collapse.

Mode 2 · Spatial regions (per slot)

Each facet is one slot; node color = that slot's assignment Ai,k (sequential: faint = low, saturated = high). Healthy: tight-ish, spatially coherent clusters, some fuzzy overlap at borders. Collapse: most facets nearly empty (degenerate) or all faint/uniform (uniform collapse).
